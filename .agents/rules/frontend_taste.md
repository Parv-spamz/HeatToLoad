# Frontend Design Taste Rules

1. **NO AI TROPES**: Never use neon blurred ambient glow blobs, pulsing circular dots, rainbow-colored stat cards, or gradient text clipping (`-webkit-background-clip: text`) on headlines.
2. **EDITORIAL TYPOGRAPHY**: Use an authoritative typographic hierarchy. Use `font-variant-numeric: tabular-nums` for all metrics, KPIs, and data tables.
3. **STRUCTURAL GRID CANVAS**: Prefer integrated 1px borders, subtle dividers, and clean grid alignments over disconnected floating glassmorphism bubbles.
4. **SEMANTIC COLOR PALETTE**: Maintain a disciplined, monochromatic foundation (deep slate `#0a0d14` or crisp light `#fafafa`) with thermal colors (amber/crimson) reserved strictly for heat/temperature surges.
5. **DENSE, JOURNALISTIC INFORMATION ARCHITECTURE**: Design like the Financial Times, Bloomberg, Linear, or Our World in Data: concise context, clean axis lines, inline sparklines, and direct data annotations.
